## Blockers and what unblocks them

1. **Mac access** — share the JARVIS folder via Remote Control, or run the 5-step check in
   `APEX_MAC_RUNTIME_AUDIT.md`.
2. **Real data** — import (or quote + approve) XAUUSD bid **and** ask history and NQ / MNQ CME
   minute bars in QuantLab → Data Vault. Free Dukascopy gold works on the Mac (the container
   could not reach it).
3. Then: APEX → Validation for each setup on real data → if a head is VALIDATED, ULTRON
   Research → *Ask SENTINEL to review* → owner *Approve*. Only then can a qualified paper signal
   (≥ 70 %) exist; zero is the expected and honest result until the statistics support one.
