# ULTRON Handoff Pack

- `ULTRON_TEAM_MASTER_BLUEPRINT.md` — detailed product and system blueprint.
- `ULTRON_CLAUDE_CODE_START.md` — execution instructions for Claude Code.
- `ULTRON_MISSION_EXAMPLE.json` — illustrative machine-readable mission plan.

**Integration:** Copy this directory under `docs/ultron-handoff/` in the *actual* JARVIS repository. Open Claude Code at the repo root and paste the content of `ULTRON_CLAUDE_CODE_START.md` or ask it to read that file. The agent must inspect the existing project rather than presume any proposed framework is installed.

This is an implementation handoff, **not** an installed or operational agent platform.
