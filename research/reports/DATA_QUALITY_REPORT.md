# DATA_QUALITY_REPORT

**Status: BLOCKED — no real market data available (2026-10-07).**

No dataset is registered in `configs/datasets.yaml`, so there is nothing to inspect.
Every attempt to obtain data is listed in [DATA_ACQUISITION_LOG.md](DATA_ACQUISITION_LOG.md).

When data arrives this file is regenerated by:

```bash
python scripts/prepare_data.py --inspect data/raw/<file>   # decide tz_in and open/close label
# register the file in configs/datasets.yaml
python scripts/prepare_data.py
python scripts/data_quality.py
```

The generated report covers, per dataset: instrument, source, file hash, date range,
row count, bar length, timezone, vendor timestamp convention, ordering, duplicate and
conflicting-duplicate timestamps, NaNs, invalid OHLC (`low <= open/close <= high`,
`high >= low`, positive prices), negative and zero volume, tick-grid conformity,
coverage per trading date and per session bucket, intraday time gaps, weekdays without
bars (holidays or vendor gaps), early closes, DST transitions, bar-to-bar price gaps
(session open vs. intrasession), isolated spikes, frozen-feed runs, contract changes,
expected roll dates against observed session-open gaps, and an adjustment hint
(unadjusted / difference / ratio).

No event study may run on a dataset before its section of this report exists and its
findings are handled in `journal/RESEARCH_JOURNAL.md`.
